# Git Tutorial

```bash
# 깃 초기화
git init

# staging 추가
git add .
# 현재폴더 기준 commit

git add -A
# 해당 repo 전역 commit
```

```bash
# commit
git commit -m "commit message"

```

```sh
# push command
git push origin main
```

```sh
# git log 명령어
git log
git log --oneline

```

alt + 위아래 방향키로 라인 위치 바꾸기
alt + shift + 위아래 방향키로 라인 복사하기
